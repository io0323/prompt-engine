■ 注意点

1. DTO に Any? を使わないこと
   Golden Dataset の input / metadata は JSONB ですが、
   DTO で Any? として公開すると springdoc の型推論に依存し、
   バージョンによって type: object になったり type: "null" になったりします
   （Issue #113 と同じ問題）。
   @Schema で明示的に表現するか、型を絞ること。
   生成された OpenAPI が意図した形になっていることを contract テストで固定する。

2. @PreAuthorize は必須
   #115 で追加した ArchUnit ルールにより、
   付け忘れるとビルドが落ちます。要求するスコープは §13.1 の
   既存の粒度に合わせること。

3. 認可テスト
   追加した全エンドポイントについて
   スコープ有り 2xx / 無し 403 / トークン無し 401 を追加すること。
   #115 で確立した軽量パターンを踏襲。
